## Key Lessons

**Log File Ownership Pattern**
- When log files have wrong permissions, it affects gateway's ability to read config
- Common in container environments where root processes touch node-owned directories
- Fix: `chown node:node /tmp/openclaw/*.log`

**Gateway Timeout Pattern**
- Timeouts during long-running cron jobs are normal (resource contention)
- Gateway recovers automatically
- Not a systemic issue unless timeouts persist without heavy load
