# Appendix E: Common Patterns Reference

## Why It Matters
This is the condensed operational grammar of the book: context files, pipelines, memory, routing, logging, and safety patterns in one place.

## Core Ideas
- Patterns repeat more often than exact tools do.
- Good automation is mostly disciplined composition of a few stable moves.
- This appendix is a fast lookup layer for real implementation sessions.

## Patterns To Keep
- Use this as the first reference when building from the handbook.
- Promote repeated patterns into repo conventions.
- Split large pattern families into focused docs if they become active work.

## What To Adopt In OpenClaw
- Treat this appendix as backlog material for future protocol docs.
- Break out high-use patterns into dedicated docs as they become real workflows.

## Risks / Limits
- Compression loses nuance.
- Pattern catalogs can feel complete while hiding implementation traps.

## Open Questions
- Which pattern families deserve their own repo docs first?
- Should this appendix be split into memory, routing, and safety follow-ups?
