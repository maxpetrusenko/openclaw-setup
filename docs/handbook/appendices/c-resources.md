# Appendix C: Resources

## Why It Matters
The handbook is not the source of truth for fast-moving details. This appendix points to the places that should validate current reality.

## Core Ideas
- Official docs for current config and API detail.
- Registries and community spaces for skills and patterns.
- External cron and debugging references for common support work.

## Patterns To Keep
- Verify handbook details against live docs before implementing.
- Keep an updated short list of canonical external resources.

## What To Adopt In OpenClaw
- Add a repo-local “verify current docs” habit before operational changes.
- Keep current links for docs, registry, issues, and schedule helpers.

## Risks / Limits
- Resources age quickly.
- Community patterns are useful but not always safe defaults.

## Open Questions
- Which external resources are actually canonical for this repo?
- Should we separate stable references from exploratory ones?
